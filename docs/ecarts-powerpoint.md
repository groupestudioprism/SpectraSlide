# SPECTRA Slide face à PowerPoint et Canva : liste des écarts

Relevé du 4 novembre 2026 (PowerPoint Microsoft 365 / web 2026, Canva Présentations 2026), comparé à SPECTRA Slide avant la mise à jour de novembre.
Sources : documentation Microsoft (Animations, Transitions, Mode Présentateur, SmartArt, Graphiques, Enregistrer), Microsoft 365 Insider « 7 nouveautés PowerPoint » (2025), hubsite365 « PowerPoint 2026 : 8 nouveautés », Canva Newsroom « New Canva Presentations features », pages Canva Présentations.

Légende de la colonne **Statut** : ✅ déjà présent avant · 🆕 ajouté en novembre 2026 · ⏳ reste à faire · ✖ écarté (raison donnée).
Priorité : **P1** très utilisé · **P2** utilisé régulièrement · **P3** occasionnel.
